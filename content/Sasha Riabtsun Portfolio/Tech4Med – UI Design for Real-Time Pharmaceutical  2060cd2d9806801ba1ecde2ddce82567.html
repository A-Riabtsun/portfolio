Tech4Med – UI Design for Real-Time Pharmaceutical Logistics

Tech4Med provides real-time visibility into pharma shipments — ensuring sensitive medical cargo arrives safely, on time, and in compliance. I collaborated with a frontend engineer to design both web and mobile interfaces that help logistics teams monitor, configure, and act on sensor data from active shipments.

While I did not have access to users or stakeholders, I worked independently to:

  • Design scalable UIs to support temperature tracking, route planning, and alert management.
  • Create responsive layouts for control rooms (web) and mobile devices used on the ground.
  • Visualize device data and alerts in a way that supports fast, confident decision-making.

My Role

As the sole UI designer on the project, I was responsible for designing both web and mobile experiences for Tech4Med. I collaborated closely with frontend engineers to craft responsive, scalable interfaces. My focus was on visual clarity, platform-specific usability, and scalable design patterns to support a complex logistics environment.

UI Design Challenges

List the core interface problems you tackled. These could include:

  • Designing a clean overview for 1000+ devices without overwhelming the user.
  • Making technical data (e.g., temperature, battery levels) legible at a glance.
  • Creating a system of visual alerts with clear severity levels.
  • Enabling efficient device filtering and navigation across screens.

Shipment Overview & Graphs

Designed detailed telemetry graphs (temperature, humidity, shock) using intuitive charting styles. I prioritized visual continuity and contrast so operators could spot anomalies without needing data analysis expertise.

Shipment Map

A scalable map interface showing active devices grouped by location. To balance clarity and density, I used color-coded status dots and hoverable clusters. A side panel allows fast filtering by alert type or cargo sensitivity.

Devices Overview

A clear, scannable list of all active tracking devices used in pharmaceutical shipments. Users can quickly check battery levels, temperature, and last activity, with easy access to scan or download data. Designed for fast decisions in high-volume logistics.

Mobile UIs

The mobile interface provides full control and visibility over sensitive shipments. Users can create new shipments, define alert thresholds, and manage origin details. Once in transit, shipments are tracked in real-time, with access to detailed sensor data (temperature, humidity, battery) and a visual journey map. Devices can be monitored via a global map or list view, and individual device data is accessible for deep-dive diagnostics.

Design Process

I worked closely with the frontend engineers to ensure feasibility, minimize development time, and build reusable components. I made interface decisions based on:

  • Industry UI patterns in logistics platforms.
  • Principles of visual hierarchy and cognitive load.
  • Hardware constraints (e.g., what data was available from devices).
  • Feedback from internal reviews.

Future Improvements

This section outlines potential enhancements identified through usability findings and stakeholder feedback.

  • Navigation: Improved structure to provide instant clarity on where the user is within the experience.
  • Filters: Enhanced filtering to make parameter selection easier and ensure selected filters are always visible.
  • Table grid: Long text strings split into separate columns to improve readability and support faster information scanning.
